# Limitations and review boundaries

1. **No runnable application:** The repository distributes documentation, not a deployable system or complete source tree.
2. **No source redistribution approval established:** Application access, developer affiliation, and a public website do not prove ownership or a license to redistribute institutional code.
3. **No screenshot redistribution approval established:** Third-party and institutional imagery may appear in the interface; the portfolio links to the live website instead of copying it.
4. **No production validation claim:** Code inspection and a small unit-test run do not establish current production uptime, end-to-end behavior, secure operation, or conference outcomes.
5. **External manuscript workflow:** The site's descriptions of peer review and paper submission do not constitute a locally implemented editorial platform.
6. **No inferred metrics:** Attendance, efficiency gains, satisfaction, citation impact, publication acceptance, and software adoption are not measured or asserted.
7. **Attribution remains reviewable:** The complete list of contributors and rights holders, including institutional teams, is not inferred from a repository or generated code.
8. **No settled 2027 program:** The next annual edition is anticipated, but its dates, venue, program, and registration have not been confirmed in this portfolio.

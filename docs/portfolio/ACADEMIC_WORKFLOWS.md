# Academic and conference workflows

| Actor | Inspected path | Scope and qualification |
| --- | --- | --- |
| Visitor | Browse conference background, themes, speakers, committee, program, and dates | Public information and the 2026 event archive; not a claim that 2027 details are settled |
| Reader | Browse a 104-page flipbook or request its public PDF | The material is an organizer-reviewed public edition; private access details and internal uploads are intentionally excluded |
| Prospective participant | Complete a registration form with affiliation and participation details | The application API records submitted information and can attempt email notices if configured; actual delivery and attendance are not independently verified here |
| Author | Read submission and peer-review guidance; follow an institutional portal link | Manuscript handling and review outcomes occur outside the inspected application API; site text describing review is guidance, not a local reviewer workflow |
| Organizer | Access a separate login-protected interface for content and registration-related records | Conceptual description only; administrator screens, records, privileges, and internal routes are omitted |

Payment administration, certificate issuance, and editorial decisions are **not** represented here as implemented internal product workflows. No registration, participant data, unpublished papers, access links, or reviewer correspondence is reproduced.

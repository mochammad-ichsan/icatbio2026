# Project overview

**Inspected project:** The first ICATBio — International Conference on Advances & Trends in Biology (2026), in the institutional context of Universitas Negeri Surabaya, Indonesia.

**Purpose:** Provide a public point of reference for the conference and a supporting organizer-facing application. Intended audiences include prospective participants, authors, attendees, speakers, organizing staff, and visitors seeking archived conference information.

**Supported scope:** Bilingual public pages, themes and speaker listings, dates, program and parallel-room schedules, a public abstract book, a registration form, and a separate administration interface for conference information. Manuscript submission is linked to an external institutional portal; this application's API does not implement manuscript review. Payment instructions may follow organizer review, but the inspected application does not constitute an online payment processor.

**Lifecycle:** The 2026 conference has concluded. The live website is expected to serve as an archive and announce the annual 2027 edition; the portfolio does not predict 2027 dates, venue, speakers, or application availability.

**Evidence boundary:** These descriptions come from inspecting application routes, page components, API handlers, manifests, and public data structures in the supplied workspace. They do not establish usage statistics, outcomes, security certification, active live workflows, or ownership of institutional materials. The public deployment is separate from this portfolio.
